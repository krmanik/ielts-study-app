# 1 Task 1 Academic
T1 basics | 150–180 words · 20 min · 1/3 of Writing score // Too long → more mistakes + less time for Task 2
T1: 3 jobs of a report | 1 Select the main features // 2 Write about them // 3 Compare them
Analyse the question | Sentence 1 = what the graphic shows // Sentence 2 = what you must do // Check: past or future? (tense) · axes + units · trends · sudden changes · stable parts
T1 report: paragraph plan | P1 Intro: paraphrase question // P2 Overview: 2–3 main trends, NO numbers // P3 Feature 1 + data // P4 Feature 2 + data // NO conclusion
T1 intro template | The [line graph] illustrates [what] in [place] from [year] to [year]. // = paraphrase sentence 1 · never copy it
Paraphrase: graphic words | the diagram → the illustration / image / graphic // shows → illustrates / depicts / represents / explains // how → the way in which / the process of
T1 overview template | Overall, it is clear that [main trend A], while [main trend B]. // It is clear from the graph that …
Bar overview template | Overall, it can be seen that although both [X] increased, [Y] had much more significant growth.
T1 body rules | Exact numbers / % · compare & contrast // unclear? → around, about, just over, just under, approximately, some // simple grammar = fewer errors
T1: which tense? | Past → past simple · Now / no date → present simple // Forecast → will / is expected to // Stay consistent!
Body openers (T1) | According to what is shown in the graph, … // To begin with, in [2012], [X] started at [6%] … // Initially, … before increasing to …
Change structure 1 | There + be + adj + noun + in + noun // There was a [sharp] [rise] in the number of [cars sold].
Change structure 2 | Noun + verb + adverb // [Fast food consumption] [rose] [steadily] between [2008] and [2011].
Verbs: UP ↑ | rose · increased · grew · climbed · jumped // soared · rocketed (very fast) · doubled · increased fourfold
Verbs: DOWN ↓ | fell · declined · decreased · dropped · shrank // plunged · plummeted (very fast) · halved
Verbs: flat | remained flat / unchanged / stable / constant at [X] // levelled off · evened out · stabilised · reached a plateau
Verbs: up-and-down | fluctuated · varied · oscillated · was erratic // dipped (fell slightly then recovered) · recovered
Peak / low phrases | peaked at · hit a peak of · reached a high of [X] // hit a low of · bottomed out at [X]
Tricky word meanings | dipped = small fall, quick recovery // bottomed out = lowest point // plummeted = huge fast fall // levelled off = NO more change
Adverbs: big vs small | BIG: dramatically · sharply · significantly · considerably · substantially · drastically // SMALL: slightly · marginally · gradually · steadily
Forecast phrases | [X] is expected / anticipated to [reach Y] by [2050]. // [X] is likely to exceed [Y] by [2041]. // The forecasted data shows …
Compare: while / whereas / although | [Spain] produces a lot of [solar power], whereas [Japan] produces almost none. // Although [Italy] produces [6m tons], [Spain] produces almost double that.
Compare: new sentence | In contrast, … · In comparison, … // [X] showed an opposite trend.
Compare: similar data | [X] produced the same amount as [Y]. · Like [X], [Y] … // Likewise / Similarly, … · Both [X] and [Y] …
Ranking phrases | [X] proved to be the most popular. · [Y] was consistently the lowest. // [X] followed the same trend as [Y]. · A similar pattern is seen in …
Useful data phrases | nearly double that of [Y] · [15%] and [8%] respectively // saw little change · a considerable change can be seen // by the end of the period
Pie chart: rules | Units may NOT be % → check! // No time → no "gradually / sharply" // 2 pies → 1 paragraph each, or compare with whereas
Pie chart phrases | [X] accounted for / made up / comprised [25%] // the largest share · a quarter · a third · just under half · the majority // more than doubled · increased five-fold · hovered between
Table: what to report? | 1 Highest & lowest // 2 Overall trend (up / down) // 3 Anomaly (odd one / biggest change)
Table: principles | Summary only, no opinion or guesses // Avoid repetition · precise words (no good / bad) // Linkers · correct active + passive
Table overview template | The table compares [four reasons] in [years], with [X] proving to be the most popular. [Y] saw the most significant growth, followed by [Z], while [W] remained relatively unchanged.
Table: common errors | ✗ between 2000 to 2020 → between … and / from … to // ✗ "what stands out from the table is" (wasted words) // ✗ levelled off when it still changed
Mixed charts: rules | Periods may differ → different tenses // Max 2–3 main features per chart // Don't describe every detail
Mixed charts: structure | Intro (40–50 words): both charts // Overview: 1 key point per chart // Body 1 = chart 1 · Body 2 = chart 2
Mixed charts: intro template | The given graphs provide information about [topic]. To be more specific, the pie chart lists [X], while the table presents [Y].
Mixed charts: phrases | Overall, the pie chart clearly shows that … The table identifies that … // by far the greatest · followed closely by · in comparison
Process: steps | 1 Understand diagram + note its words // 2 Group stages into 2 main features (2 body paras) // 3 Plan 2–3 min · write 15 · check 2–3
Process: intro template | The diagram illustrates how [X] is produced. // The procedure for [X] is as follows.
Process: overview template | There are [seven] key stages in this process, beginning with [A] and concluding with [B].
Process: sequence words | First of all, → Then, → Next, → After that, → At the next stage, → Finally, // This completes the procedure.
Process: grammar | Present simple · PASSIVE: is + past participle // The nectar [is deposited] into the cells. // This is done by …
Process: linking phrases | in order to · as a result · whenever // Once this is done, … · which also causes … // It is this [substance] that forms the basis of …
Map: analyse | Find: new features · removed features · unchanged features // Note years → past / future tense
Map: intro + overview | The maps show [place] as it was in [1995] and how it is predicted to look in [2025]. // Overall, [place] will become more [residential], at the expense of [natural features].
Map: organise body | Option A: 1 paragraph per time period // Option B: compare area by area (north, east …)
Map: change verbs | was built / constructed · was demolished · was replaced by // was turned / converted / developed into · was upgraded to · was extended · was relocated
Map: more phrases | used to be much less built-up · was dominated by · was situated at // took the place of · remained untouched // The only feature to remain the same is …
Map: location words | north / south-east … · to the left / right of · adjacent to · next to · between // in front of · behind · nearby · along the riverfront / seafront / lakefront
# 2 Task 1 Letters (GT)
GT letter basics | 150+ words (aim ~180, not >240) · 20 min // Types: application · reference · accommodation · complaint
How letters lose marks | Irrelevant info · missing a bullet point · misreading the question
Letter: which tone? | Stranger / company → FORMAL // Known boss, landlord → SEMI-FORMAL // Friend → INFORMAL
Letter structure | Greeting // Reason for writing // 1 paragraph per bullet (×3) // Closing line // Sign-off + name
Formal greeting → sign-off | Dear Sir / Madam → Yours faithfully // Dear Mr / Ms [Surname] → Yours sincerely // + full name under it
Formal: reason for writing | I am writing to … · I am writing concerning … // I am writing on behalf of … · I am writing in reply to your advertisement in [X].
Formal: asking | I would be grateful if you could … // I wonder if you could … · Could you …? // (use INDIRECT questions)
Formal: referring to their letter | As you stated in your letter, … // With regard to … · Regarding … · Concerning …
Formal: closing line | If you require any further information, please do not hesitate to contact me. // I look forward to hearing from you / to your reply.
Reference letter: structure | P1 Reason for writing + how long you've known them // P2 Skills + experience // P3 Character + personal qualities // P4 Why suitable + closing
Reference: always mention | People skills · English skills // Time management · previous experience
Reference: phrases 1 | To whom it may concern, // I have known [X] for [ten years]. // It is my pleasure to recommend her for the position of [X].
Reference: phrases 2 | I have no hesitation in recommending [X]. · I am confident that … // [X] possesses a thorough grounding in … // which will stand her in good stead
Reference: closing | I recommend [X] without reservation — she would be an excellent asset to your company. // Please do not hesitate to contact me if you have any questions.
Character adjectives | sociable · reliable · self-confident · outgoing // hard-working · communicative · committed
Cohesion devices | Linking words (firstly, in addition) · discourse markers (moreover, by way of example) // Reference pronouns (this, they) · relative clauses · substitution ("…and so were the staff") // Don't overuse!
Application letter: must include | Where you saw the ad + which position // Language skills // Suitability: experience, qualifications, qualities // Available for interview · CV enclosed
Application: opening | I wish to apply for the role of [X] advertised in [Y]. // Please find enclosed my CV for your consideration.
Application: body | I have over [five years] experience in [X], and I believe the skills built up during this time make me the perfect candidate. // I am confident that I can bring this level of success to your organisation.
Application: closing | I am available for an interview at any time convenient to you. // Thank you for your time and consideration. I look forward to meeting you to discuss my application further.
Complaint letter: structure | P1 Why you went + you're dissatisfied + problem 1 // P2 Problem 2 // P3 Problem 3 // P4 What you want + suggestions
Complaint openers | I am writing to complain about … · I would like to express my dissatisfaction with … // I am writing to express my concern about … · I feel I must complain to you about … // I wish to complain in the strongest terms about …
Complaint: error in records | I am writing to inform you of an apparent error in your records. // I feel sure there must be some mistake. · Please recheck your records.
Complaint: problem words | poor standard of service · slow service · rather rude staff // defective / faulty goods · badly scratched · dented packaging · travel delays
Complaint: linking problems | Firstly, … · A further cause for complaint was that … // Not only did we receive [X], but we were also [charged full price].
Complaint: demand action | I must insist that you … · I must urge you to … // I would be grateful if you would send me a full refund / a replacement. // I suggest that immediate steps be taken.
Complaint: returning goods | I am returning [X] to you for repair / inspection. // I am enclosing the broken [radio]; please send me a replacement.
Complaint: ending | I do not usually complain, but, as a loyal customer, I hope you will be interested in my comments. // Perhaps it would be appropriate to … // I look forward to hearing from you at your earliest convenience.
6 rules of formal style | 1 Understate (rather disappointed) // 2 No ! // 3 Use passive // 4 No contractions // 5 No phrasal verbs / idioms // 6 Formal structures (Although …)
Formal sentence example | Informal: The waiter did offer us another dish, but it was cold again. // Formal: Although we were offered an alternative dish, when it was delivered it was cold again.
Make it formal 1 | I reckon → It is my opinion that // On top of this → Furthermore // What's more → In addition // To finish → In conclusion
Make it formal 2 | loads of rubbish → a great deal of litter // a load of problems → several problems // the teacher I'm talking about → the teacher in question
Make it formal 3 | you could → it may be possible for you // stop → prevent · better → more suitable // state of → condition of
Phrasal verb → formal | talked into → convinced · done up → refurbished // cut off → isolated · put up → accommodated // make up for → compensate · chuffed → thrilled
Formal verbs 1 | go → depart · do → carry out · give → provide // keep → retain · stop → cease · look for → seek // help → assist / aid
Formal verbs 2 | get → obtain · want → desire · ask for → request // work → function · show → demonstrate // live → reside · need → require
Formal other words | later → subsequently · enough → sufficient // more (info) → further · so → hence / therefore // cheap → inexpensive · little → a lack of
CV attached or enclosed? | Email → attached // Letter → enclosed
Informal: rules | Dear / Hi + FIRST name only // Contractions OK · 1–2 idioms (not more) // State purpose in intro · use personal experience
Informal vs formal example | Let me know if you need anything else. // = Should you require any further information, please do not hesitate to contact me.
Informal: opening | Hi [Name], I just wanted to let you know that … // I'm writing because I couldn't wait to tell you about …
Informal: sorry / favour | Sorry for … · I want to apologise for … // I was wondering if you'd help me out with … · Could you do me a big favour? // I'd be really grateful if you could …
Informal: good / bad news | I was absolutely thrilled to hear … · I'm over the moon … // I'm afraid … · Unfortunately … · Regrettably … · I've got some bad news.
Informal: endings | Take care · Hope to see you soon · Keep in touch // Can't wait to see you · Don't be a stranger! // All the best, [First name]
Formal letter checklist | Formal tone? · All bullets covered? · All questions asked? // Questions indirect? · Paragraphs? · Proofread?
# 3 Task 2 Rules & Style
Essay basics | 250+ words (not much more) · 40 min · 2/3 of score // Same for Academic + GT · formal English
Word guide | Intro ~50 · Body ~170 (2–3 paras) · Conclusion 30–40 // Conclusion: NO new ideas
Examiner's 4 criteria | Task Response: answered all? clear opinion? // Coherence: planned? linked? // Vocabulary: range + spelling // Grammar: complex + error-free + punctuation
Sentence rules | Every sentence = gold, no useless ones // Concise > long · write for a human reader
Paragraph formula | 1 Topic sentence (link to previous para) // 2–3 sentences: explain + evidence + example // 1 concluding / linking sentence
Topic vs task | Part 1 = topic (what about) // Part 2 = task (what to do) // Underline keywords · answer the question, not what you want to write
Topic / subtopic / instruction words | Topic = general subject // Subtopic = exact focus (write ONLY about this) // Instruction = what to do
First sentence of essay | General, but not too general // ✗ memorised frame that doesn't fit ("There are those who argue water is necessary") // ✓ Water shortages affect millions of people worldwide each year.
Linking paragraphs | However, there are those who argue that … (other side) // Another argument in favour of [X] is that … (same side)
"This + noun" linker | This argument / approach / issue / factor // This evidence / policy / measure / trend …
Show importance | One of the most significant [problems] of … is … // [X] is becoming increasingly important / challenging // [X] has been extensively researched.
Strong adj + noun | increasing concern · a key role · a major problem // heightened awareness · rapid development · a dramatic increase // unprecedented interest · a serious impact on
Use nouns (efficient) | They increased production → an increase in production // Better employee training would increase efficiency. // The implementation of this strategy may lead to reductions in pollution.
Hedging (be balanced) | ✗ These people are completely wrong. // ✓ It might be the case that … · Recent research suggests that this is not the case.
Hedging example | ✗ Students have low maths skills due to calculators. // ✓ Over-dependence on calculators may have a negative effect on some students. // (don't hedge obvious facts)
Hedging words | arguably · it is reasonable to assume that · tend to // are more likely to · in many cases · may / might
Be realistic | Avoid: all · every · none · always · never · completely // Use: many · a large number of · most
Avoid "thing" | ✗ learn many new things // ✓ learn many new skills, such as time management and communication.
Upgrade basic words | to → in order to / so as to · like → such as // get → receive / obtain · help → assist / support
Not only … but also | Not only does [working] provide [experience], but it also improves [social skills].
Formal "more" | more → an increasing / a growing number of (countable) // → an increasing amount of (uncountable) // a lot → significantly more · a significant / sizeable number of
Punctuation don'ts | No etc. or … in lists → A, B, and C // No question marks · no ! // No contractions
Don't start with But / And / Because | But → However, // And → Furthermore, / In addition, // Because → Since / As a result,
Most vs almost | most = the largest part: most people, in most cases // almost = nearly: almost 10%, almost 700 million
Rookie errors | Articles (a / an / the) · subject-verb agreement // singular / plural · countable / uncountable
No "I think" in body | I think / I believe → intro + conclusion only // Body: Some people believe … · Others argue … · It is probably true to say that … · Nobody would dispute the fact that …
No I / you / we in body | ✗ If I study at university, I … // ✓ If students study at university, they …
Global perspective | ✗ Factories in my city pollute the river. // ✓ Factories across the world release toxic waste into water supplies.
Repetition: when OK? | Repeat key ideas with SYNONYMS to remind the reader // global warming → rising temperatures → global temperature increases
Plan (5 min) | Underline keywords → type → opinion → 2–3 main ideas → notes per paragraph // Brainstorm in simple words first (like chatting) · mind-maps / lists
Task 2 final checklist | Answered all parts? · Clear opinion throughout? // Didn't copy question? · Relevant examples? // ≥250 words? · Grammar, spelling, linking checked?
# 4 Task 2 Essay Types
5 essay types | Opinion · Discussion · Advantages/Disadvantages · Problem/Solution · Two-part question
Spot the type | agree / disagree / to what extent → OPINION // discuss both views → DISCUSSION // advantages outweigh → ADV/DIS // problems / causes + solutions → P/S // two direct questions → TWO-PART
Opinion: 2 question types | Type 1: both sides given → agree with one / partly agree // Type 2: one side given → agree 100% / disagree 100% / partly agree
Opinion: plan | 1 Find the opinion in the question // 2 Decide agree / disagree // 3 Brainstorm main points // 4 Short notes for each reason
Opinion: structure | Intro: paraphrase + clear opinion // B1: reason 1 → explain → example // B2: reason 2 → explain → example // Concl: summary + restate opinion
Opinion: intro template | The question of whether or not [X] has been the subject of recent public discussion. [X], in my opinion, should [Y], on the grounds that [reason].
Opinion: body template | Firstly, one argument in favour of [X] is that [reason]. // Without [X], … · Even in cases where … // This can severely affect … (consequence)
Opinion: conclusion | In conclusion, [X] is crucial for any society seeking [sustainable progress]. // Hence, it would be appropriate for [the government] to …
Opinion: key vocabulary | sufficient · funding · fulfil (dreams) · undoubtedly // discourage X from -ing · be unwilling to // carry the burden of · less appealing · hence
Balanced (partly agree) essay | Agrees with SOME parts of both sides // ONE clear opinion · no contradictions // Body explains why
Balanced: intro template | Some people think that [X]. In my opinion, [Y]. So while it is important to [X], a degree of [Y] is always required.
Balanced: key phrases | There are numerous reasons to … · This leads to … // [X] and [Y] are not mutually exclusive. // renders [X] more feasible
Adv/Dis: 2 question types | With opinion: "Do the advantages outweigh the disadvantages?" → say which side wins // Without: "Discuss the advantages and disadvantages." → just both
Adv/Dis: tactic | Pick a side · 2 advantages + 1 disadvantage // Treat the complex side briefly
Adv/Dis: structure | Intro: paraphrase + opinion // B1: advantage 1 // B2: advantage 2 // B3: disadvantage // Concl: summary + restate
Adv/Dis: intro template | The question of whether the benefits of [X] outweigh the drawbacks has been sparking debate for several years. I believe that [X] is beneficial on many levels and that, therefore, the advantages clearly outweigh the disadvantages.
Adv/Dis: body phrases | A variety of advantages are created by … · For starters, … // Furthermore, [X] benefits society in many other ways. // One potential stumbling block is …
Adv/Dis: conclusion | After taking into consideration all of the points made above, I do not see any significant disadvantages to [X], provided [Y]. // … from both an economic and a cultural standpoint.
Adv/Dis: quick check | Paraphrased question · clear opinion in intro // Same opinion all through // Each para: 1 point + logical example · conclusion sums up
Adv/Dis: vocabulary | boost = enrich = improve · solidify = reinforce // insufficient = a shortage of · diverse = varied // we must foster = we must encourage
P/S: 3 types | Problem + solution (most common) // Cause + solution // Solution only (rare, easiest)
P/S: question phrases | What problems / issues arise … and how can they be addressed? // What measures could be introduced …? // How can this be resolved / prevented?
P/S: 2 structures | A: B1 = 2–3 problems · B2 = solutions // B: each paragraph = 1 problem + its solution
P/S: common mistakes | Too many ideas · not enough detail // Problems not linked to solutions // Not specific · no world view · writing causes when not asked
P/S: intro template | A growing number of people are [X]. However, problems such as [A], [B], and [C] can have a serious impact on [Y]. This essay will examine these issues and propose potential solutions.
P/S: body phrases | Firstly, [X] has resulted in a shortage of … // …, which contributes to the second issue, [Y]. // …, which is the third issue to be addressed.
P/S: solution phrases | As a first step, governments should … // Something governments must improve is … // Another possible solution is the implementation of …
P/S: conclusion | In summary, [X] is causing several issues. To address them, we should [A], [B], and [C].
P/S: more phrases | Multiple problems arise as a result of … // [X] puts a significant strain on … // We should start taking appropriate measures, such as …
Discussion: tactics | Both sides, EQUAL attention // Clear opinion, consistent // Pick the easiest opinion (not judged on it)
Discussion: structure | Intro: paraphrase + outline + thesis // B1: view 1 // B2: view 2 // B3: why you agree / disagree + examples // Concl: summary + your side
Discussion: intro template | There is an ongoing debate as to whether [X]. While proponents of [X] argue that [A], many people believe that [B]. Although both sides make very valid points, I would argue that [opinion].
Discussion: body openers | On the one hand, it could be argued that … // On the other hand, in some cases, … // Furthermore, it is often claimed that …
Discussion: opinion paragraph | However, in my opinion, … // Therefore, it seems counterintuitive to … // An added benefit of [X] is that …
Discussion: conclusion | In conclusion, I firmly believe that [X] is far more critical to … than [Y]. // As a result, I agree with the proponents of [X].
Two-part: structure | Intro: paraphrase + outline both answers // B1: answer Q1 + world-view example // B2: answer Q2 + example // Concl: summary + opinion
Two-part: mistakes | Not answering BOTH questions // Not naming both answers in the intro
Two-part: intro template | At present, there are increasingly more [people] who [X]. This essay will discuss [the main driving forces behind this] and why I believe it is mostly a [negative] trend.
Two-part: body phrases | It is reasonable to assume that one of the main driving forces behind [X] is [Y]. // In addition to the influence of [Y], … // Although there are many benefits to [X], it is mostly negative when overused.
# 5 Task 2 Phrases & Templates
Give your view | I would argue that … · I firmly believe that … // It seems to me that … · I tend to think that … // In my experience, … · It is undoubtedly true that …
Others' views | People argue that … · Some people think that … // Many people feel that … · There has been a growing body of opinion that …
Supporters vs opponents | Supporters of [X] argue that … // Opponents of [X] point out that … and argue that … // One of the main arguments in favour of [X] is that …
Refute an argument | I am unconvinced that … · I do not believe that … // It is hard to accept that … · It is unjustifiable to say that … // There is little evidence to support …
False argument: introduce | It could be argued that … · Some people would argue that … // It is often suggested that … // There is also the idea implicit in the statement that …
False argument: demolish | This is partly true, but … // To a certain limited extent, there is some truth in this … // However, the implication that … is an oversimplification. // This argument has a certain logic, but …
Correct argument: propose | It is clear that … · Obviously, … · On the contrary, … // The real situation is … // It is therefore entirely wrong to suggest that …
Concede, then argue | While I admit that [X], I would argue that [Y]. // However, whilst I agree that …, I am less convinced that … // Admittedly, … · It cannot be denied that …
Support / examples | For example, … · For instance, … · Indeed, … · In fact, … // Statistics demonstrate … · It can be generally observed that … // Let me illustrate … · If this were the case …
Define / explain | By this I mean … · In other words, … // This is to say … · To be more precise, … // Here I am referring to …
Stress a point | The most crucial point is that … · Another point is that … // Of crucial importance, in my opinion, is … // Surely … · Arguably …
Clarify meaning | My response to this argument depends on what is meant by … // There is surely a difference between [X] and [Y]. // I intend to illustrate how these differences are significant.
Suggest solutions | However, it is possible to tackle this serious issue in several ways. // One approach would be … · A second possibility would be to … // This could involve … · … would be particularly beneficial.
Misc. connectors | Either way, … · In any case, … // Of course, it goes without saying that … // In the final analysis, … · Ultimately, …
Linkers: use SPARINGLY | First / second · Moreover · In addition · Furthermore // Nevertheless · On the one / other hand · Besides // Consequently · In contrast · In comparison
Linkers: use MODERATELY | While · Meanwhile · Although · Even though // In spite of / Despite the fact that · Since // As a result · However · Similarly · Thus · In turn
Listing evidence in a paragraph | Firstly, … Secondly, … Thirdly, … // (inside one paragraph or to start each paragraph)
Cause → effect phrases | This leads to … · This can result in … // [X] has resulted in … · …, which contributes to … // which would, no doubt, benefit …
Intro openers: the debate | The question of whether [X] has sparked widespread public debate. // There is currently a discussion as to whether … // There are differing opinions on whether … // People have different opinions on whether or not …
Intro openers: context first | In today's society, numerous [cities] are confronted with the question of whether or not to … // Many [students] nowadays [X]. However, whether … has turned into a hotly disputed topic.
Intro: state your position | As far as I'm concerned, … · I genuinely think that … // I mostly agree / disagree with the notion that … // I am a firm believer that … · I personally believe that …
Intro: disagree with a claim | Generally, it is commonly believed that [X]. The following are some of the reasons why I find this to be untrue.
Intro: "will never replace" | There is disagreement over whether [X] can take the place of [Y]. [X], in my opinion, will never be able to replace [Y] completely.
Intro: good or bad change | Several issues are unavoidably raised when [X]. I believe that this is a negative change.
Body openers (templates) | To begin with, … · First and foremost, … // Possibly the most important reason to consider is that … // It is well understood that …
Body depth phrases | [X] and [Y] are inextricably linked. // A more in-depth examination would reveal that … // In the long run, … · [X] should be given precedence over [Y].
Conclusion openers | In conclusion, … · To summarize, … · In summary, … // Considering everything, I believe that … // After taking into consideration all of the points made above, …
Conclusion: concede + verdict | To summarize, [X] may have some advantages, but it will never completely [Y]. // [X] may [take up space], but its importance should not be overlooked.
Conclusion: call to action | We must learn to [respect X]. // The government would be wise to … // We should start taking appropriate measures, such as …
